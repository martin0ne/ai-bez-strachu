# Plan nawyku JEŚLI → TO

> Narzędzie wspólne dla obu kursów (Gollwitzer: implementation intentions). „Będę używać AI" nic nie znaczy. „JEŚLI [sytuacja] → TO [krok]" — działa.

## Jak to działa

Plan warunkowy łączy nowy nawyk z **istniejącym trybem dnia**: nie musisz pamiętać — sytuacja-sygnał przypomina sama. Wypełnij własne linie długopisem albo z pomocą asystenta (instrukcja asystenta zna ten plan i pilnuje go w rozmowach).

## Gotowe przykłady (start — możesz przepisać)

| JEŚLI … | TO … |
|---|---|
| dostanę długi mail / pismo do przeczytania | wklejam do AI i proszę o 5 punktów prostym językiem |
| muszę napisać trudną wiadomość | szablon A — mail w moim stylu (kontekst + ton + limit) |
| czegoś nie rozumiałem i boję się zapytać | szablon D — „wytłumacz jak 12-latkowi" |
| planuję coś z ograniczeniem (czas/pieniądze) | szablon C — plan do odhaczenia |
| AI podaje ważny fakt (zdrowie/prawo/pieniądze) | 3-check: źródło → liczby → logika |

## Zasady dobrego planu JEŚLI-TO

1. **Wyzwalacz z Twojego dnia** („gdy siedzę przy śniadaniu", „gdy dostanę pismo") — nie abstrakcja.
2. **Konkretne działanie** („wklejam i proszę o 3 punkty") — nie „będę używać".
3. **2–3 plany, nie 10** — nawyk buduje się na powtórzeniach, nie na liście postanowień.
4. **Przegląd po 14 dniach:** co zadziałało zostało, co nie — wyrzucasz bez żalu.
