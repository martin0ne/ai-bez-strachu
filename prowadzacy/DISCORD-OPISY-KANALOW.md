# Discord — opisy kanałów (wklej w opis każdego kanału)

> Opis kanału = ta mała linia pod nazwą (Discord: kliknij kanał → „Edytuj kanał" → pole „Temat kanału"). Każdy opis mówi: po co kanał jest i jaka jest jedna zasada. Krótko — to nie regulamin.

---

## 📌 START

### `#start-tutaj`
```
Wchodzisz pierwszy raz? Tu masz wszystko: 3 kroki na start + linki + zasady. Przeczytaj przypięte, potem przejdź do #przedstaw-sie.
```

### `#ogloszenia`
```
Tylko prowadzący pisze. Daty sesji, materiały po każdej sesji, zmiany planu. Wycisz ten kanał? Nie — tu jest wszystko, co ważne.
```

### `#przedstaw-sie`
```
Imię (lub pseudonim) + jedno zdanie: czego chcesz się nauczyć. Bez CV — po prostu przywitaj się. To buduje grupę.
```

## 📚 SESJE

### `#sesja-1-pierwsze-kroki`
```
Sesja 1: co to jest AI + Twoje pierwsze pytanie. Tu pytaj o wszystko między S1 a S2 i wrzucaj wyniki ćwiczeń.
```

### `#sesja-2-przepisy`
```
Sesja 2: gotowe szablony — streszczenie, plan, wyjaśnienie. Wrzucaj swoje wersje i porównuj z grupą.
```

### `#sesja-3-maile-i-formula`
```
Sesja 3: maile w Twoim stylu + formuła KIM → CO → FORMA. Utknąłeś na formule? Napisz tu — pomogę grupa i prowadzący.
```

### `#sesja-4-bezpieczenstwo-i-nawyk`
```
Sesja 4: czerwona lista pełna, „pewny ton ≠ prawda", plan JEŚLI→TO. Tu zadajesz pytania o bezpieczeństwo bez wstydu.
```

## 🔄 PRAKTYKA

### `#dziennik`
```
Codziennie 1 zdanie: „dziś zrobiłem X z AI". Małe wpisy budują nawyk — to najważniejszy kanał kursu. Zero presji na jakość.
```

### `#pokaz-wynik`
```
Wrzuć prompt + wynik AI. Grupa komentuje. Zasada: zanim poprosisz o feedback — skomentuj 2 obce.
```

### `#pytania`
```
Wszystkie pytania o AI i zadania kursu. Nie ma głupich pytań — jest 5 sekund ciszy przed odpowiedzią i pomysł „może to głupie". Zadaj je.
```

## 🛠 SERWIS

### `#pomoc-techniczna`
```
Konto, hasło, Zoom, dźwięk, kamera — wszystko techniczne. Nie ma problemu zbyt małego. Merytoryka → #pytania.
```

### `#feedback`
```
Kurs był Ci pomocny? Coś nie działa? Pomysł na ulepszenie? Napisz: SUKCES / PROBLEM / IDEA + jedno zdanie. Każdy głos trafia do raportu ulepszeń.
```

### `#oflagowane-do-marcina`
```
Prywatny kanał prowadzącego (sprawy eskalowane, osobiste, wrażliwe). Jeśli coś Cię dotyczy prywatnie — napisz w DM do Marcina, przeniesiemy tu.
```

---

*Zasada pisania opisów: maks. 2 zdania · pierwsze zdanie = po co kanał · drugie = jedna zasada/nakierowanie · ton kursu (zero żargonu, „na ty", bez wstydu).*
